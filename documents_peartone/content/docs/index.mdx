## Welcome

This is the documentation for **Peartone**, a music streaming platform (album, artist, track, playlist, likes, history, and admin upload features) built with a Node.js/Express + Sequelize backend and a React + Vite frontend.

## Tech Stack

| Layer | Technology |
|---|---|
| Backend | Node.js, Express, Sequelize, PostgreSQL |
| Frontend | React 19, Vite, Tailwind CSS, React Router |
| Realtime | Socket.IO |
| Auth | JWT + Google OAuth |
